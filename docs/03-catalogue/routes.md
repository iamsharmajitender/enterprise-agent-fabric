# Catalogue routes

Active Pattern 0–3 rows. Ids and demo paths match [`create-seed-data.sql`](../run/scripts/create-seed-data.sql), [`jobs.json`](../run/dummy-request/job/jobs.json), [`chats.json`](../run/dummy-request/chat/chats.json), and wrappers under [`dummy-request/`](../run/dummy-request/README.md).

**Dummy `completed` ≠ dataflow proof.** Use [D13 verification checklist](../tasks/dataflow-plan.md#verification-checklist-d13). Proof routes: `purchase_refund` (D5), `policy_memo` / `pack_then_review` (D7).

Status vocabulary ([`../02-understand/status.md`](../02-understand/status.md)):

- **`runs`** — stages execute as hydrated. HTTP = `goal` ∪ schema-selected **slots**. LLM reads **notes**. Workflow prefetch stages pack `working.slots.prefetch`. Branch, `human_gate`, `kind=agent`, and `loop=checkpoint` resume are wired.
- **`catalogue-only`** — Runtime does **not** execute: `conversation`, `long_term`, Pattern 3 inner **allowlist** enforcement.
- **`prefetch mode only`** — route names `deterministic_prefetch` but Pattern 0/1 has no workflow prefetch stage; pack does not run.
