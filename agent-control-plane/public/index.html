Glossary

What each catalogue row and field means. Click a section to open it; opening another closes this one.

Route

A named agent use case. Front Door asks Data Plane to decide; a route outcome freezes this row at a version and starts Agent Runtime. Chat never sees the route id. Jobs send it explicitly. This Control Plane lists those rows and their pointers to prompt, workflow, and manifest.

Identity

Route identity fields
TermMeaning
Routeroute_id Stable name of the use case, for example fee_explain. Decide matches chat text onto this id. Jobs POST it. Changing behaviour is a new version of this id, not a rename in place.
Intentintent_label Classifier label for the user goal. Usually matches the route id. Used on decide and in clarify chips. Not shown to the chat client as an id.
Autonomyautonomy_mode Who chooses the next step inside the run after the route is chosen. Not classify. Options below. Does not choose how the run is started.
Route versionroute_version Pin unit. A freeze copies this version. In-flight runs keep it even if a newer row becomes Active. History on a route is these versions, newest first.
Description Human summary of what the route does. Shown on the list and detail. Not sent to the model as the prompt; that is the prompt pack.

Autonomy options

Autonomy mode values
TermMeaning
Single inference0 One LLM call. Prompt only. Cannot take tools, retrieve tools, a workflow, memory, or retrieval. Pattern 0 may return the inference body synchronously.
Autonomous1 The model chooses tools from the hydrated manifest in a loop, up to max loop steps. No workflow stages.
Deterministic2 Workflow stages run in a fixed order. The model does not pick the next tool. Prefetch can be a forced retrieve stage.
Guided3 A workflow frames the run; the model may still choose within that frame. Use when some steps are fixed and some are judged.

Activation

Route activation fields
TermMeaning
Activation targetactivation_target Which Agent Runtime Front Door starts. Empty means the shared runtime. Channels never dial this URL. Isolate a box for PCI, release, or network; do not create a new target just to get a different identity.
Agent clientagent_client_id Which robot mints the agent token for this route. User ≠ agent ≠ runtime workload. A new use case is a new route and a new client id, not a new runtime.

Policy and model

Route policy and model fields
TermMeaning
Policypolicy_profile Policy profile copied onto the run pin. Runtime enforces it on tool calls; a published capability is still not permission. high_risk_step_up (High risk) — higher bar when the route can take costly or irreversible actions. read_only_standard (Read only) — default for most catalogue routes. low_risk_chat (Low risk) — cheap chat / single-inference with no tools.
Modelmodel_profile Pointer into dataplane.model_profiles. Changing model is a catalogue edit, not a runtime flag. reasoning-standard — plan / multi-step / high-stakes synthesis. fast-chat — cheap synthesize / classify. lightweight-chat — no-tools / cheap chat.
Fallbackfallback What to do if the primary path fails. Seed value: clarify. Does not start a different route by itself.
Max loop stepsmax_loop_steps Cap on autonomous loop iterations. Unused on single inference. Keeps a long tool loop from running without bound.

Tools and retrieval

Route tools and retrieval fields
TermMeaning
Manifesttool_manifest Pointer to the tool list. The route has no inlined tools[]. Runtime hydrates the whole pinned manifest before the LLM. Empty / omitted means no tools (typical for single inference).
Retrievalretrieval How the route searches corpora. Omit the row when there is no index. Scope is corpus ids, not the capability catalog. tool (UI: Tool) — model or stage retrieves via a normal domain capability over the scope. deterministic_prefetch (UI: Prefetch) — designer-forced pack before generate; prefetch stage invoke is empty today.

Memory

Route memory fields
TermMeaning
Memory profilememory_profile What the run may keep. Fields: conversation, working, loop, long_term. Field values: session, checkpoint, none, retrieve_only. TTL is hours. Isolation options: tenant, user, session. Empty on routes that must not remember. Runtime honors working and loop today.

Artifacts

Route artifact pointers
TermMeaning
Workflowworkflow_id Pointer to ordered stages. Required for deterministic and usual for guided. Empty when the model chooses tools freely (autonomous) or when there is a single inference.
Promptprompt_id Pointer to the prompt pack the LLM sees. Host text plus optional per-role fragments. Not the route description field.
Output schemaoutput_schema_id Expected structured output for the route, when one is pinned. Empty means free-form text is allowed.
Eval suiteeval_suite_id Optional slice-3 quality suite for this route after start (tool order, citations). Empty is correct for free-form chat. The CI routing golden set is the catalogue board in Data Plane tests, not this pointer. Not used on the hot path.

Access

Route access fields
TermMeaning
Required claimsrequired_claims Entitlements the user or jobs caller must hold. Decide intersects the active table with these claims. Missing claims → not eligible, not a silent route.
Channelschannels Where this route is eligible. Options: web, api. A route can be api-only (jobs) or web-only (chat).
Chatchat_visible Whether the route appears as a chat option. Options: true, false. False means event-only or jobs-only; decide still entitles it when the caller sends the route id.
Capability

A published, versioned tool or API in the registry. Manifests refer by id@version. Runtime hydrates every ref once at pin, then invokes after policy check. A published capability is not permission to call it. Chat never sees this catalog as JSON.

Capability fields
TermMeaning
Capabilityid Stable product name, for example ocr_extract or start_contract_review. Not a vendor name. Agent developers copy this id into a manifest.
Kindkind Two kinds only. Do not add kinds for retrieve, prompts, workflows, memory, or MCP. Domain domain — governed business API (method, path, auth). Agent agent — starts another catalogue route via API Front Door jobs with a fixed route id. Not a direct Agent Runtime URL.
Owner Team that may publish the next version. Not the team that authored the parent route.
Version Immutable. Changing the contract is a new version, not an edit in place. Overwriting a published version is rejected. Manifests pin exact versions; never latest.
Status Options: draft, published, deprecated. Manifests may only refer to published. Deprecated shows as Retired in this UI.
Description For developers and later the model. Becomes part of the tool schema the LLM sees after hydrate.
Input schema JSON Schema for arguments the model must supply. Copied onto the run pin at hydrate. Not fetched when the model first names the tool.
Output schema JSON Schema for what the tool returns to the model. Separate from the route output schema.
Invoke How runtime calls the real API after policy check. Domain: method, path, auth to the business API. Agent: POST jobs with a fixed route id. Not an MCP URL and not an Agent Runtime URL.
Snippet Developer documentation on the capability. Not used at runtime and not sent to the model.
Corpus

A retrieve index row in Data Plane. Routes name corpus ids in retrieval.scope; workflow stages may pin one id in stage.corpus. Runtime looks up each id and POSTs to that row’s gateway url — the route never stores a retrieve URL. Not a capability kind and not long_term memory.

Corpus fields
TermMeaning
Corpuscorpus_id Stable index name, for example policy-engine or clause-index. Appears in route retrieval.scope and on named retrieve stages. Two ids in scope are two lookups and two POSTs, then merge — never two indexes in one search call.
Display name Human label for operators and this Control Plane. Not sent to the model as a prompt.
URLurl Retrieve gateway endpoint. Agent Runtime POSTs {collection, goal} (and merged pack fields on prefetch routes). Local Compose uses agent-fabric-mocks POST /v1/search.
Collectioncollection Index or collection name when several corpora share one gateway host. Required on shared gateways; may match corpus_id when each index has its own row.
Authauth How Runtime authenticates to the gateway, for example workload-oauth. Distinct from capability invoke auth on retrieve tools.
Owner Team that owns the index and may publish the next row cut.
Status Options: draft, published, deprecated. Runtime must POST only published rows. Unpublished or missing corpus → fail closed on prefetch. Deprecated shows as Retired in this UI.
Regionregion Optional residency or region hint for the index. Empty when not pinned.

Retrieval modes

How routes use corpora
TermMeaning
Prefetchdeterministic_prefetch Route retrieval.mode. App packs every id in scope before generate. Empty-invoke prefetch stages write working.slots.prefetch; the model cannot skip search.
Retrieve tooltool Route retrieval.mode. Named retrieve capability over scope. Workflow stage.corpus picks which scoped id that stage uses. Still a normal domain capability HTTP call.
Prompt

Versioned instructions the LLM sees for a route. The route stores a prompt id pointer. Single inference routes are prompt-only: no tools, workflow, or retrieval.

Prompt fields
TermMeaning
Promptprompt_id Stable pack name. Several routes may share one pack. A route pin copies the version current at freeze.
Versionprompt_version Immutable cut of the pack. Edit the text by publishing a new version and pointing the route at it.
Owner Team that publishes the next pack version.
Status Options: draft, published, deprecated. New pins use the live published pack when the route points at it. Deprecated shows as Retired in this UI.
Hosthost System-level prompt text for the pack. This is what the model sees as the host / system message.
Rolesby_llm_role Optional fragments keyed by LLM role. Empty when the host text is enough. Each fragment has task_type: plan, synthesize, or classify. Pack keys exclude none. classify — LLM only; skip HTTP; bindable output_schema validated. synthesis — LLM only; user-facing answer or memo; Pattern 0 host node. query_formulation — LLM writes the retrieve query, then HTTP. Stage-only none — HTTP if invoke url is set; otherwise no-op (not a pack key).
Workflow

Ordered stages for deterministic or guided runs. The route stores a workflow id pointer. Autonomous routes leave this empty so the model picks tools from the manifest. A stage is not a capability by itself; it names a tool or an LLM step. Control Plane columns: Stage, Tool, Type, LLM role, Corpus, Branch, Gates. Pattern 2/3 run stages in order today; branch and human_gate are catalogue-only until dataflow D8–D9.

Identity

Workflow fields
TermMeaning
Workflowworkflow_id Stable name of the stage list. Several route versions may pin the same workflow.
Versionworkflow_version Immutable cut. Adding or reordering stages is a new version. The freeze copies this version.
Status Options: draft, published, deprecated. Deterministic routes should pin a published workflow. Deprecated shows as Retired in this UI.

Stage fields

Workflow stage fields
TermMeaning
Stageid Stable step name inside the workflow, for example ocr or manual_review.
Tooltool Capability name on the route manifest. Empty on LLM-only, prefetch placeholder, or human_gate stages.
Typetype Optional. Omitted = ordinary tool / LLM stage. Seed option: human_gate (pause for a human; no tool URL). Seed: purchase_refund, kyc_onboarding. Not executed in this Runtime yet.
LLM rolellm_role Options: none (HTTP if url set, else no-op), classify, synthesis, query_formulation. Same values as prompt pack roles (pack keys exclude none).
Corpuscorpus Optional corpus id for a retrieve stage, for example clause-index. Route retrieval scope is the full list; this names one corpus on the stage.
Branchbranch Map from a slot value to the next stage id, for example high → manual_review, low → activate_account. Catalogue-only; Runtime stays linear today.
Side effectside_effect Set true for a write / money / freeze step. Gate chip: Side effect.
Approvalrequires_approval Set true to latch the write until a human packet exists. Pair with human_gate. Gate chip: Approval. Catalogue-only today.
Allowlistallowlist Guided (pattern 3) tool names the model may choose within this stage. Catalogue-only; Runtime does not enforce the list yet.
Max tool callsmax_tool_calls Guided cap on tool calls inside the stage. Catalogue-only today.
Manifest

Named list of tools a route may call. Each tool is a capability reference. The route stores only the pointer. Adding a tool or bumping a capability version is a new manifest version. Runtime downloads the whole pinned manifest, then hydrates every ref before the LLM.

Manifest fields
TermMeaning
Manifestmanifest_id Stable name of the tool list. none on a route means no tools.
Versionmanifest_version Immutable cut. Bump when a capability id or version on a tool row changes. Cache key is this pair.
Description Human summary of what this tool set is for. Not sent to the model as a prompt.
Status Options: draft, published, retired. Routes should pin a published manifest.
Tools Rows the model may call. Each has a name, capability id, capability version, policy action, and risk tier. No inlined OpenAPI; schemas come from hydrate.
Actionpdp_action Policy action checked before invoke. Agent policy, not the publisher API contract. A published capability still fails if this check denies.
Riskrisk_tier Risk tier on the manifest tool row. Checked with pdp_action before invoke. low — read or low-impact (search, OCR, confirm). medium — draft, score, match, or notify. high — side-effect or money-moving (freeze, post refund, activate, start child agent).
Status

Lifecycle of a catalogue row. Home tiles and list tabs use these four. Decide reads the Active table for new turns. A freeze copies a version and never re-reads Active.

Catalogue status values
TermMeaning
Active Live version used for new turns. For routes this is the live pointer. For registry rows, live published.
Published Released and eligible to pin, but not the live pointer. Older cuts stay here so history and in-flight pins still resolve.
Draft Not published. New turns do not use it. Safe to edit before a version is frozen.
Retired Deprecated or withdrawn. Kept for history. New manifests must not refer to retired capabilities.
