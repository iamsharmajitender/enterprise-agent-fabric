## What this is not

A portfolio of chatbots. A framework you drop into every domain. A place where Legal, payments, and KYC each invent identity, approval, and audit again.

People and systems never dial those URLs. They come in **one door**. The fabric verifies, routes, runs, and records. The domain AI does the work.
