## Locked fabric rules

1. **Four jobs.** Front Door entitles, pins, starts. Data Plane classifies. Control Plane is control and audit. Runtime runs.
2. **Two Front Door fleets, one contract.** Separate process at production scale. Runtime return is not a third door.
3. **Jobs name `route_id`.** Skip classifier and clarify. Do not skip entitle and record.
4. **Generic chat still classifies.** Hints are eligible and chat-visible.
5. **Only `route` starts Runtime.** Clarify and abstain never pin.
6. **One Agent Plane per trust domain.** Not one mega-agent.
7. **Three principals.** User ≠ agent ≠ Runtime workload.
8. **Capabilities are references.** Runtime hydrates the whole pinned manifest before the model.
