## Locked fabric rules

1. **Four jobs.** AFD entitles, pins, starts. Data Plane classifies. ACP is control + audit. AR runs.
2. **Two AFD fleets, one contract.** Separate process (FR-9). `{runs_topic}` is AR return.
3. **Jobs name `route_id`.** Skip classifier and clarify. Do not skip entitle + record.
4. **Generic chat still classifies.** Hints are eligible + chat-visible.
5. **Only `route` starts AR.** Clarify / abstain never pin. Default start is async `202`.
6. **One Agent Plane per trust domain.** Not one mega-agent.
7. **Three principals.** User ≠ agent ≠ AR workload.
8. **Capabilities are references.** AR hydrates the whole pinned manifest before the LLM.
