# agent-fabric-docs

The Enterprise Agent Fabric documentation site — a [Docusaurus](https://docusaurus.io) project. Content lives in [`docs/`](docs/); the reader-facing entry point is the [documentation map](docs/index.md).

## Run it

```bash
npm install
npm start          # dev server on http://localhost:3000/enterprise-agent-fabric/ with hot reload
npm run build      # production build; fails the build on broken links
npm run serve      # serve the production build
npm run diagrams   # regenerate static/diagrams/ from diagram-sources/
```

The site is a GitHub Pages **project site**, so every path is served under the `/enterprise-agent-fabric/` base URL — locally as well as in production.

## Publish

Published at **https://iamsharmajitender.github.io/enterprise-agent-fabric/** by [`.github/workflows/deploy-docs.yml`](../.github/workflows/deploy-docs.yml): pushes to `main` that touch `agent-fabric-docs/` build and deploy; pull requests build only. Repository **Settings → Pages → Source** must be set to **GitHub Actions**.

## Layout

| Path | What it holds |
| --- | --- |
| [`docs/`](docs/) | Every published page. Numbered folders set sidebar order |
| [`static/diagrams/`](static/diagrams/) | Generated SVG figures plus the standalone HTML editorial source of each |
| [`static/fixtures/`](static/fixtures/) | Frozen request and response JSON, served at `/fixtures/<name>.json` |
| [`diagram-sources/`](diagram-sources/) | Python generators for `static/diagrams/`. Edit these, never the SVGs |
| [`tasks/`](tasks/) | Engineering plans and todos. Not published |
| [`intent/`](intent/) | The v1 lock: what to build. Not published |

## Adding a page

Drop a `.md` or `.mdx` file into the right folder under `docs/`. The sidebar is autogenerated, so there is no nav list to update. Two conventions matter:

- **Order** comes from the `NN-` filename prefix, which is stripped from the URL. `docs/01-concepts/02-authoring-a-product/03-prompts.md` serves at `/concepts/authoring-a-product/prompts`.
- **Section labels** come from the `_category_.json` beside the folder; **page labels** come from `sidebar_label` in frontmatter, falling back to the H1.

Link to other pages by their site path (`/concepts/authoring-a-product/route`), not by relative file path. Link to anything outside `docs/` — source trees, task plans, the repo README — with a full GitHub URL. `npm run build` fails on anything that does not resolve.

Images and file links written as Markdown (`![alt](/diagrams/x.svg)`, `[fixture](/fixtures/x.json)`) pick up the base URL on their own. Standalone HTML in `static/` is the exception: a Markdown link to it fails the link check and a raw `href="/diagrams/x.html"` drops the base URL, so link it as `<a href={useBaseUrl('/diagrams/x.html')}>` with `import useBaseUrl from '@docusaurus/useBaseUrl';` at the top of the page.
